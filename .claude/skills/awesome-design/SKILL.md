# Awesome Design

`resources.md` in this folder is the Awesome Design list (github.com/gztchan/awesome-design), grouped by category: Stock, Icon and Logo, Color, Typography, Toolkit, Prototyping, Mockup, User Testing and more.

When a task needs a design resource, search `resources.md` for the matching category and pick links from there. Check each resource's licence before using its assets in a published video.
